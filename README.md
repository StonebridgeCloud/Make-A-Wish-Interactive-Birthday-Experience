# 🎂 Make A Wish – An Interactive Birthday Experience

A magical, interactive birthday celebration created using **Python, Pygame and NumPy**.

Make a wish, gather the magical energy, and blow out the birthday candles! This project transforms a traditional birthday moment into an immersive visual experience with elegant animations, glowing effects and interactive controls.

## ✨ Project Highlights

- **Interactive Birthday Experience:** A guided celebration with animated introduction and countdown.
- **Procedural Birthday Cake:** A detailed, two-tier cake with decorative frosting, golden details and nine candles.
- **Interactive Candle Blowing:** Hold the SPACE key to build wind energy and release it to blow out the candles.
- **Dynamic Flame Effects:** Animated candle flames with realistic flickering and glowing light.
- **Particle Animations:** Golden floating particles, sparkling effects and wish-energy particles.
- **Smoke Effects:** Animated smoke rising from extinguished candles.
- **Fireworks & Confetti:** A celebratory finale with fireworks and falling confetti.
- **Animated Typography:** Elegant text reveals, countdowns and birthday messages.
- **Portrait Display:** Designed with an 800 × 1200 resolution.
- **Smooth Animation:** Built with a 60 FPS target.

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Make-A-Wish-Interactive-Birthday-Experience.git
```

**2. Navigate to the project folder**

```bash
cd Make-A-Wish-Interactive-Birthday-Experience
```

**3. Install the required libraries**

```bash
pip install pygame numpy
```

**4. Run the project**

```bash
python make_a_wish.py
```

## 🎮 Controls

| Key | Action |
|---|---|
| ENTER | Start the celebration / move through intro scenes |
| SPACE (Hold) | Build wind energy to make your wish |
| SPACE (Release) | Blow out the birthday candles |
| R | Restart the birthday experience |
| F | Toggle fullscreen |
| ESC | Exit the application |

**Tip:** Hold SPACE long enough to build sufficient wind energy. Release it to blow out the candles. A stronger wish can extinguish more candles!

## 🎨 Visual Experience

The entire experience is generated programmatically using Python, Pygame and NumPy.
